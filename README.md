# Список задач

Веб-приложение для ежедневных задач. Без сборки и зависимостей: чистые HTML, CSS и JavaScript.

## Возможности

- Добавление задач (кнопка или Enter); пустые задачи и лишние пробелы отбрасываются
- Отметка выполненных (клик по чекбоксу или по тексту) с анимацией галочки и зачёркивания
- Удаление задачи с возможностью отменить в течение 6 секунд
- Очистка всех выполненных одним действием (тоже с отменой)
- Сохранение после обновления страницы (`localStorage`)
- Фильтры «Все / Активные / Готово» со счётчиками
- Прогресс дня: в шапке по одной секции на каждую задачу, выполненные закрашиваются
- Светлая и тёмная тема по настройке системы
- Адаптивная вёрстка, управление с клавиатуры, видимый фокус, поддержка `prefers-reduced-motion`

## Запуск

Откройте `index.html` в браузере. Шрифт Onest подгружается с Google Fonts, без интернета используется системный.

## Структура

```
index.html   разметка
style.css    токены (цвета, шрифты) и стили
script.js    состояние, отрисовка, работа с localStorage
```

## Технические решения

- Данные хранятся как массив `{ id, text, done }`, на каждое изменение пишутся в `localStorage`. Битые или недоступные данные не ломают приложение.
- Текст задач выводится через `textContent`, поэтому вставка HTML невозможна.
- Обработчики событий навешены на список целиком (делегирование), а не на каждую строку.
- При отметке задачи строка не пересоздаётся, а обновляется на месте: так срабатывают CSS-переходы. Полная перерисовка списка нужна только при добавлении, удалении и смене фильтра.
- После перерисовки фокус возвращается на тот же элемент, чтобы навигация с клавиатуры не сбивалась.
- Цвета и размеры вынесены в CSS-переменные, тёмная тема переопределяет только их.
